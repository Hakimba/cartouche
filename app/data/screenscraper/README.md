Which disc or cartridge images [ScreenScraper](https://www.screenscraper.fr) has for each game of the reference
lists, so the app downloads only those, never asking which game a file is. One file per console, a line per release of
the reference lists (No-Intro, Redump): its name, its ScreenScraper game id, and its textures (`support-texture`) as
`region` or `region[disc]`. Built by asking ScreenScraper once for every release, by its reference hashes and size;
rebuilt for each release of the app. The first line is the date of the answers.
